# ZXV × Sano Collaboration Pack

Bundled from the supplied BangSano/Sano archives for local review and optional staging.

## Included themes
- Stellar
- Billing
- Enigma
- Elysium
- Nebula
- Nightcore (CSS + background)

## Included references
- Frontend reference: `source-reference/index.tsx`
- Location reference: `source-reference/alocation.sh`
- Node reference: `source-reference/createnode.sh`

Legacy theme archives are kept as inspectable packages and are **not injected into the live Panel automatically**. This prevents an older theme from overwriting ZXV or incompatible Pterodactyl source files.

> Note: The supplied Elysium archive had a corrupt ZIP directory entry. The files that could be extracted were repackaged into a clean `ElysiumTheme.zip` inside this collab bundle; the recovered contents are preserved as provided and are still treated as a legacy theme requiring review before live installation.
